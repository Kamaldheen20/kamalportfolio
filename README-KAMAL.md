# Kamal — AI Developer Portfolio

A responsive, dark-themed portfolio customized for Kamal, a final-year B.Sc. Artificial Intelligence student.

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Before publishing
- Replace the general GitHub profile links on project cards with each project's repository URL.
- Add your real email address and LinkedIn profile URL.
- Your uploaded portrait is included at `images/kamal-profile.jpg` and is displayed prominently in the profile card.
- Verify each project description and list only projects that you can demonstrate.

## Deploy
This is a static site and can be deployed to GitHub Pages, Vercel, or Netlify. Upload the contents of this folder or connect the repository.
